# To-Do List App

A simple To-Do List application built with Python, tkinter, and SQLite. It allows users to manage tasks by adding, editing, deleting, and marking them as completed, with support for deadlines and priority levels. The app also features notifications for upcoming deadlines.

## Features

- Add, edit, delete, and mark tasks as completed
- Set deadlines in YYYY-MM-DD format and priorities (1-5)
- Receive notifications for tasks due within 24 hours
- Responsive GUI built with tkinter
- Persistent storage using SQLite

## Tech Stack

- **Python**: Core programming language (version 3.6 or higher)
- **tkinter**: GUI framework for the user interface
- **SQLite**: Lightweight database for task storage
- **datetime**: For handling deadlines and notifications

## Requirements

- Python 3.6 or higher
- No external dependencies required (uses Python standard libraries)

## Installation

```bash
git clone https://github.com/Druid45ra/todo_app.git
cd todo_app
python main.py
```
