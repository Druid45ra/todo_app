# To-Do List App

A simple To-Do List application built with Python, tkinter, and SQLite.
## Features
- Add, edit, delete, and mark tasks as completed.
- Set deadlines and priorities for tasks.
- Receive notifications for upcoming deadlines.
## Requirements
- Python 3.6 or higher
